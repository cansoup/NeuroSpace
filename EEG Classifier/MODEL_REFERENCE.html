The one-line answer

It’s EEGNet (Lawhern et al., 2018) — a compact ~1.5K-parameter CNN for EEG. I tuned it with 5-fold stratified cross-validation on a 12-point grid over the number of temporal filters, temporal kernel length, and dropout. Best config was F1=4, D=2, kern_len=64, dropout=0.6.

Architecture — layer by layer

Input: (batch, 1, 4 channels, 625 samples) — 2.5 s of 4-channel EEG at 250 Hz.
Output: 3 logits → softmax over {left hand, right hand, both hands}.

Defined at eeg_online_classifier.py (lines 151–202).

Block 1 — temporal + spatial filter

  1. Temporal conv Conv2d(1, F1=4, kernel=(1,64), padding=(0,32)) — learns time-frequency kernels across the full 2.5 s window (captures mu 8–12 Hz and beta 13–30 Hz oscillations).
  2. BatchNorm2d
  3. Spatial depthwise conv Conv2d(F1=4, F1*D=8, kernel=(4,1), groups=F1) — per-temporal-filter spatial projection over the 4 electrodes. With groups=F1, each temporal filter gets its own independent 4-electrode mixing weight (the EEGNet depthwise trick; keeps parameters low).
  4. BatchNorm2d → ELU → AvgPool(1,4) → Dropout(0.6)

Block 2 — depthwise-separable temporal conv

  1. Depthwise temporal conv Conv2d(8, 8, kernel=(1,16), groups=8) — per-channel temporal refinement.
  2. Pointwise conv Conv2d(8, F2=16, kernel=(1,1)) — 1×1 mixing that recombines channels. The depthwise+pointwise pair is roughly 2× cheaper than a full conv of the same size.
  3. BatchNorm2d → ELU → AvgPool(1,8) → Dropout(0.6)

Classifier

  • Flatten → Linear(flat_size → 3). flat_size is computed by a dry-run at construction time (_get_flat_size, line 194) rather than hardcoded.

Total params: ~1,550. Tiny on purpose — the dataset is ~90 trials, so a large model would just memorize. 

# Minimal EEGNet skeleton (eeg_online_classifier.py)
class EEGNet(nn.Module):
    def __init__(self, n_classes=3, n_channels=4, n_samples=625,
                 F1=4, D=2, F2=16, kern_len=64, dropout=0.6):
        self.block1 = nn.Sequential(
            nn.Conv2d(1, F1, (1, kern_len), padding=(0, kern_len // 2), bias=False),
            nn.BatchNorm2d(F1),
            nn.Conv2d(F1, F1 * D, (n_channels, 1), groups=F1, bias=False),
            nn.BatchNorm2d(F1 * D),
            nn.ELU(),
            nn.AvgPool2d((1, 4)),
            nn.Dropout(dropout),
        )
        self.block2 = nn.Sequential(
            nn.Conv2d(F1 * D, F1 * D, (1, 16), padding=(0, 8),
                      groups=F1 * D, bias=False),    # depthwise
            nn.Conv2d(F1 * D, F2, (1, 1), bias=False),   # pointwise
            nn.BatchNorm2d(F2),
            nn.ELU(),
            nn.AvgPool2d((1, 8)),
            nn.Dropout(dropout),
        )
        self.classifier = nn.Linear(self._get_flat_size(n_channels, n_samples), n_classes)

Preprocessing (identical offline and online)

Defined in preprocess() at eeg_online_classifier.py (lines 88–105).

  1. Notch 50 Hz (Q=30) — kills powerline hum.
  2. Bandpass 8–30 Hz (Butterworth order 4) — isolates the mu + beta motor-imagery bands.
  3. Per-channel z-score — centers/scales each channel independently, stabilizes BatchNorm downstream.

Channel selection: electrodes [0, 1, 3, 4] from the 6-channel headset — channel 2 is saturated and always skipped.

Offline the filters are zero-phase (filtfilt); online they’re causal (lfilter) so real-time predictions don’t need future samples.

Training recipe (online trainer, in the main script)

At eeg_online_classifier.py (lines 463–519):

  • Loss: CrossEntropyLoss with inverse-frequency class weights (handles any class imbalance).
  • Optimizer: Adam, lr=8e-4.
  • Scheduler: CosineAnnealingLR(T_max=epochs, eta_min=1e-5) — smooth decay to ~0 by the end.
  • Epochs: 300 in production, batch size 16 train / 32 val.
  • Data augmentation (lines 112–144): Gaussian noise (σ=0.08), ±40-sample time-shift, per-channel amplitude jitter ×U[0.8, 1.2], and 30% chance of zero-ing one channel. Disabled in the tuning notebook to keep the comparison against classical baselines fair.
  • Validation: 5-fold stratified CV (seed=42) for diagnostics, then retrain on all 90 trials for the final exported checkpoint.

The hyperparameter sweep — what you actually did

In notebooks/04_eegnet_sweep.ipynb:

Step 1 — window-length check (cell 4)

Tested 2.0 s / 2.5 s / 3.0 s windows with default config. 2.5 s is what the online classifier uses, so the sweep only moves off it if the F1 gain justifies the deployment-side retrain.

Step 2 — architecture grid (cell 6)

Exhaustive grid over 12 configurations:

Parameter Values What it controls
F1 {4, 8} Number of temporal filters in block 1
D {2} (fixed) Spatial depth multiplier — pinned to 2 because with only 4 electrodes a higher D over-parameterizes spatial mixing
kern_len {32, 64} Temporal kernel length (≈128 ms vs 256 ms @ 250 Hz)
dropout {0.5, 0.6, 0.7} Regularization strength

Each config is 5-fold stratified CV’d. Per-config training: 100 epochs, Adam lr=8e-4, CosineAnnealing, class-weighted CE, batch 16. Selected on macro-F1 (not accuracy — macro-F1 is robust to class imbalance and surfaces per-class weaknesses).

Step 3 — best config retrain (cell 7)

Picks the top row of the grid by macro-F1, then re-runs 5-fold CV with epochs=200 for a final scored result.

Step 4 — final weights export (cell 10)

Retrains the winner on all 90 trials (no held-out split) for 200 epochs and saves to results/04_eegnet_tuned.pt in the {'state_dict', 'classes', 'cfg', 'window_sec', 'channels'} format that load_model() (line 205) in the online classifier expects.

What isn’t swept (and why)

  • Learning rate / optimizer / batch size: fixed because with 90 trials, adding more grid dimensions just overfits the CV folds.
  • F2: derived as F1 * D * 2 per EEGNet convention, not an independent knob.
  • Augmentation: off during the sweep (apples-to-apples vs classical baselines), reinstated when the same architecture is retrained in the main script for deployment.

Online inference

At eeg_online_classifier.py (lines 287–357):

  • Pulls EEG from an LSL stream into a 625-sample ring buffer.
  • Once full, classifies every 0.5 s (125-sample step).
  • Runs preprocessing → EEGNet forward → argmax.
  • Majority vote over last 3 predictions smooths out single-window noise before emitting the final label to an LSL marker stream.

Answers you can give verbatim

“What model did you use?”

EEGNet — a compact depthwise-separable CNN specifically designed for EEG. Around 1,500 parameters, three conv blocks: a temporal filter that learns time-frequency patterns, a depthwise spatial filter across electrodes, and a depthwise-separable block that refines temporal dynamics and mixes channels. Output is a 3-class softmax.

“Why this model?”

The dataset is small — ~90 trials of 4-channel EEG at 250 Hz — so a large model would overfit. EEGNet’s depthwise-separable convolutions give it the inductive bias that EEG needs (separate temporal and spatial processing) while keeping parameter count low enough to train reliably on this data.

“What tuning did you do?”

Exhaustive grid over the number of temporal filters, temporal kernel length, and dropout — 12 configurations total. 5-fold stratified cross-validation on each, scored by macro-F1 so class imbalance doesn’t bias selection. Winner was F1=4, D=2, kernel=64, dropout=0.6. I also checked window length (2.0 / 2.5 / 3.0 s) separately, kept 2.5 s. Learning rate, batch size, and optimizer were fixed — grid dimensions are cheap on paper but each one I add makes CV-overfit more likely on 90 trials.

“What about augmentation / regularization?”

Dropout 0.6 (high — tuned) plus training-time augmentation: Gaussian noise, small time-shifts, per-channel amplitude jitter, and random channel drop-out. Class-weighted cross-entropy handles any imbalance. Cosine annealing on learning rate from 8e-4 down to 1e-5 over training.

“How did you evaluate?”

5-fold stratified CV on the 90 trials, reporting mean ± std of macro-F1, accuracy, per-class F1, and an aggregated confusion matrix. Majority vote of 3 at inference time smooths live predictions.
